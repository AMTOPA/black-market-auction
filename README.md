# 🎩 黑市拍卖行 Black Market Auction

> 一款上头的地下拍卖经营游戏：信息不完全 + 读人心理 + 抬价反杀 + 资产经营。
> 你是一名混迹地下拍卖会的古董商，要用有限线索判断拍品真实价值、判断买家意图，低买高卖，让净资产滚雪球——直到破产清算。

## ✨ 玩法速览

- **连续经营制**：每场拍卖会 8 件拍品，与 4 位性格迥异的 AI 买家同场竞价。
- **信息不对称**：只看得到公开估价、两条线索与市场行情；可以花「情报点」深入调查真伪/估价/买家/线索可信度。
- **竞价博弈**：小幅 +5% / 标准 +15% / 强势 +35% / 退出；**抬价是正式策略**——但玩脱了必须接盘。
- **五种买家**：收藏家（为套装发疯）、黄牛（只捡便宜）、赌徒（赌未知）、老狐狸（故意抬价）、富豪（对顶级货强势）。
- **结算经营**：出售 / 鉴定 / 持有 / 抵押四选一；市场每场波动，还有新闻提示与特殊买家高价收购。
- **收藏套装**：凑齐整套出售可获 1.5~3 倍溢价。
- **7+ 拍卖等级**：跳蚤市场 → 私人仓库 → 古董沙龙 → 黑市拍卖 → 富豪密拍 → 国家级藏品交易 → 无尽高端市场。
- **双模式**：`自由经营`（稳步扩张，看谁走得远）/ `竞速挑战`（8 场定胜负，比拼最终净资产，适合冲榜）。
- **随机事件**：每场开场与场后结算各有一个随机事件——神秘注资、行情爆炒、债主上门、特殊买家现身……时局常变，机会与风险并存。
- **暗线委托**：每场随机接到一份委托（拍下某类藏品、拒绝赝品、低价捡漏、达成利润目标等），完成即获现金与声望。
- **声望体系**：完成委托攒声望——达到 50 入场费 8 折，达到 100 特殊买家必现。
- **每日补助**：每天可领一次真实现日补助（游客本地领取，登录用户服务端领取），金额随身价上涨，保证亏光也能东山再起。
- **排行榜**：不登录也能玩；**想上榜必须注册登录**，支持按「全部 / 自由经营 / 竞速挑战」筛选，按净资产排名。
- **v2 扩展**：场型随机化 / 多身份流派 / 每日挑战 / 传奇拍品 / 生涯声望解锁 / 本场结算明细 / 信息卡三选一 / 现金利息引擎——每场都有新期待。

## 🚀 运行

需要 Node.js ≥ 22（内置 `node:sqlite`）。

```bash
npm install
npm run dev        # 开发模式，打开 http://localhost:3000
```

生产模式：

```bash
npm run build
npm start
```

## 📦 技术栈

- Next.js 15（App Router）+ React 19 + TypeScript
- 纯手写 CSS 设计系统（暗黑鎏金地下拍卖行风格，无 UI 框架）
- `node:sqlite` 本地数据库（账号 / 会话 / 排行榜 / 每日补助），无需额外数据库服务
- WebAudio 合成音效（无外部音频文件）
- 存档存于浏览器 localStorage；排行榜数据存于 `data/game.db`

## 🔑 账号与排行榜

- 游客：直接开始游戏，存档在浏览器本地，**不能上榜**，每日补助走本地。
- 登录：首页「登录 / 注册」，用户名 2-16 位（中英文/数字/下划线），密码 ≥6 位。
- 成绩：一轮经营结束后（破产、主动结束或完成竞速挑战），登录用户自动提交成绩。自由经营按净资产峰值计分，竞速挑战按最终净资产计分。

> 说明：游戏逻辑在浏览器端运行，排行榜为“轻量反作弊”（服务端记录峰值、每日补助服务端限领）。若未来部署到云端（如 Vercel），需要把 `node:sqlite` 换成云数据库。

## 🎮 操作

- 拍卖现场：根据公开信息判断，选择加价幅度或退出；用情报点深入调查。
- 结算：逐件处理藏品——着急用钱就卖（未鉴定会被压价）、有闲钱先鉴定再卖、看好后市就持有（付仓储费）、缺现金可抵押（3 场内可赎回）。
- 破产：现金与信用不足以支付下一场入场费时触发强制清算；清算后仍资不抵债则本轮结束。

## 📁 目录结构

```
src/
  app/            # 页面与 API 路由（auth / leaderboard / daily-claim）
  components/     # UI：首页、拍卖现场、结算、排行榜、登录等
  game/           # 纯逻辑：engine（状态机）/ generator（拍品与买家生成）/ events（随机事件与委托）/ config（数值平衡表）/ content（文案池）/ save / audio
  lib/            # db（node:sqlite）/ auth（scrypt+会话）/ api（客户端请求）
data/game.db      # 运行时生成的本地数据库（已 gitignore）
```

## ⚖️ 数值

所有平衡数值集中在 `src/game/config.ts`，改一处即可调难度。初始现金 30,000、库存 6 格、信用额度=净资产×30%、利息 8%/场、情报 2 点/场（留 1）、真伪倍率 1.0/0.45/0.08、仓储费 1%/件/场、抵押=保守估值×50%。
